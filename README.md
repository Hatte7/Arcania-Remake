# Arcania Remake

Jogo em HTML/CSS/JavaScript puro — remake de um projeto anterior chamado "Arcania".

## Arquivos

- `main.html` / `main.css` — tela inicial
- `jogo.html` / `jogo.css` — tela de jogo
- `main.js` — lógica compartilhada

## Como rodar

Abra `main.html` no navegador, ou sirva a pasta com `python3 -m http.server` e acesse localmente.

## Stack

HTML5, CSS3, JavaScript vanilla.

## Status

Protótipo em desenvolvimento.
